INSTALLATION

Install CreatorBucket

Google Play

CreatorBucket will be available on Google Play after its first public release. This page will then link directly to the store listing.

Test builds

Pre-release Android builds may be shared with invited testers. Only install a test build from a link supplied by CreatorBucket or its official GitHub project.

Android requirements

CreatorBucket supports Android 8.0 and later. It uses Android’s Share sheet, file picker, and system media deletion confirmation.
